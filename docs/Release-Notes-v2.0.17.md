# v2.0.17 发布说明

## 自动学习可靠性

- 课程目录存在加载层或无法解析任务时不再误判为全部完成；失败恢复按课程隔离断点和统计。
- 暂停、停止会同步控制视频，并在导航、播放器等待和交卷前检查任务是否仍有效。
- 考试只有检测到成功结果页后才推进断点。
- 平台提示应先完成某节时，从完整课程模型回查前置任务；兼容空白、零宽字符和同名标题，并允许重做被目录误标为 100% 的任务。

## 控制面板与更新

- 新版本检查改为显示可关闭的版本对比卡片，由用户明确点击后再打开 GitHub Releases。
- 修复面板折叠后展开按钮被标题栏内容裁切的问题。

## Server酱³

- 仅在 HTTP 成功且响应业务状态码为 `0` 时判定发送成功，完成通知使用有限退避重试并防止并发重复发送。
- 已保存 SendKey 不再回显到页面 DOM，并提供显式清除按钮。

## 验证

- JavaScript 语法检查、Node 全量回归和 diff 空白检查全部通过。
- 更新提醒和折叠面板已通过本地 Edge 桌面及移动设备指标渲染检查；未使用自动化操作登录或验证码。
