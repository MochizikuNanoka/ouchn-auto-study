## 标题空白兼容

- 同一学习单元的视频与考试标题即使只在普通空格、全角空格或不可见空白上不同，也会正确配对。
- 考试收到同名“请先完成”提示时，优先重做同章节、同学习单元且唯一的视频任务，避免重复点击考试并刷新循环。
- 目录重新定位和断点恢复使用相同的严格标题等价规则；实际文字不同的相似标题仍不会被视为同一任务。
